# ByteCat IP

## Character Definition

ByteCat is a software engineering cat who works inside AI systems.

Unlike XiaoHei, ByteCat is a curious problem solver that enjoys debugging, coding and building intelligent applications.

## Appearance

* White cat body
* Round glasses
* Blue scarf
* Simple hand-drawn style
* Black sketch outlines
* Neutral and focused expression

## Personality

* Curious
* Logical
* Hardworking
* Calm under pressure
* Enjoys solving technical problems

## Common Responsibilities

* Debugging software
* Building AI models
* Organizing data
* Fixing broken workflows
* Connecting ideas into systems

## Restrictions

* Not a cute mascot
* Not an anime character
* Not overly detailed
* Must actively participate in the illustration
* Must be part of the core metaphor

## Evaluation

If ByteCat is removed and the illustration still works the same way, then ByteCat is not involved enough and should become the main actor of the scene.
